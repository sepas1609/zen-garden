# 🌊 Zen Garden Ripples — Fluid Wave Equation Simulation

Zen Garden Ripples simulates 2D discrete wave propagation across a viscous water surface.

## 💧 Wave Equation Mechanics
- **2D Discrete Wave Equation**: Computes wave height displacement field $u(x, y, t)$ through finite difference time-domain (FDTD) numerical discretization.
- **Surface Tension & Damping**: Natural exponential damping prevents numerical standing wave resonance.
- **Caustic Shading**: Real-time refractive distortion simulating sun caustics on shallow pool bed.
